#  Weather App

A responsive weather application built using HTML, CSS and Vanilla JavaScript.


## About

This Weather App allows users to search for any city and view its current weather information.

The application uses the Open-Meteo API to fetch real-time weather data.

##  Features

* Search weather by city
* Search using the Enter key
* Current temperature
* Feels-like temperature
* Humidity
* Wind speed
* Today's high and low temperature
* Weather condition with icon
* Automatic Day/Night theme
* Responsive design
* Loading and error messages

##  Technologies Used

* HTML5
* CSS3
* JavaScript
* Fetch API
* Async/Await
* Open-Meteo API

##  How It Works

1. User enters a city name.
2. The application uses the Open-Meteo Geocoding API to find the city's coordinates.
3. The coordinates are used to request current weather data.
4. JavaScript displays the weather information dynamically on the page.
5. The application's theme changes according to the city's local day/night status.
